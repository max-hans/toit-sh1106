# Sh1106

Driver for the small black-white OLED display that runs off the Sh1106 driver.

Tiny OLED Displays usually come with two kinds of drivers. The Ssd1306 or the Sh1106 driver.

This package is a port of the original [Ssd1306](https://github.com/toitware/toit-ssd1306) package created by [@floitsch](https://github.com/floitsch).

Driver for the SH1106 OLED display.  This is a 128x64 monochrome
display.

On the Wemos Lolin board the I2C bus is connected to pin5 (SDA) and
pin4 (SCL).

This package also contains an experimental driver for the SSD1306
in SPI mode.

**This is currently untested since I don't have one at hand.**
